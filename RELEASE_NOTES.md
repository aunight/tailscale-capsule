2.1.0 — 首個公開版本 / First public release

繁體中文

1. 原生 WinUI 3 系統匣面板，玻璃與操作色隨 Windows 主題色即時變更。
2. 裝置清單加入狀態色點、平台圖示、IP 複製與淡入淡出篩選；Mac 與 iPhone 使用不同圖示。
3. 提供 Taildrop 檔案傳送與本機傳送／接收紀錄，保留進度、結果及未確認狀態。
4. 加入穩定版更新通知，更新下載執行前核對 GitHub 的 SHA-256。
5. 提供繁體中文／英文介面切換、安裝包、可攜式版本、中英文介紹與示範截圖。

驗證：自動化狀態／紀錄／更新檢查與本機事件監聽已完成；未自行向其他裝置傳送檔案，完整跨裝置流程仍待驗證。

English

1. A native WinUI 3 tray panel with glass and controls that follow the Windows accent color.
2. Device status dots, platform icons, IP copying, and a fading online filter, with distinct Mac and iPhone icons.
3. Taildrop sending and local send/receive history, including progress, results, and explicitly unconfirmed states.
4. Stable-release update notifications with GitHub SHA-256 verification before running downloaded installers.
5. English and Traditional Chinese interfaces with a language selector, installer and portable packages, bilingual documentation, and screenshots using fictional data.

Validation: automated status/history/update checks and the local event subscription passed. No files were sent to another device during verification; full cross-device behavior still needs end-to-end validation.
